# Amostras de projetos (Nexo)

Solte aqui projetos reais e variados para calibrar a extração/classificação do Nexo (Fase 0-4).

**O que ajuda mais:**
- Volumes diferentes (memorial, LD, capa, pranchas, volume montado).
- Tipos de volume diferentes (romano/numérico), prefeituras diferentes.
- Casos de borda: nomes de arquivo bagunçados, disciplinas misturadas, PDFs escaneados (OCR).

**Como organizar (sugestão):** uma subpasta por projeto, ex.:

```
docs/samples/
  117-25-ubs-criciuma/
    memorial.pdf
    ld.pdf
    pranchas.pdf
  040-26-escola-chapeco/
    ...
```

Sem estrutura fixa obrigatória — pode soltar solto também. Nada aqui é enviado pra fora; é usado localmente para testar a classificação.
