---
category: acoes
---

Alternância de 2–4 opções num trilho afundado; a pílula do escolhido desliza (mola). Para filtros e modos de vista, não para navegação. `rotulo` é o nome acessível do grupo.

```jsx
<Segmento rotulo="Período" valor="30" onTroca={() => {}} opcoes={[
  { valor: "7", rotulo: "7 dias" }, { valor: "14", rotulo: "14 dias" }, { valor: "30", rotulo: "30 dias" },
]} />
```
